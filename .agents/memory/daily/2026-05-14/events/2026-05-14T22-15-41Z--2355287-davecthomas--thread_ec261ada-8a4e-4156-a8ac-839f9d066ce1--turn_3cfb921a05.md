## Why

- The render engine's value proposition (ADR-0001: 'YAML in, single self-contained HTML out') is only reachable if a non-engineer can produce valid YAML. Until this cluster, the only paths to a valid spec were hand-editing against the Pydantic models or copying the public sanitized sample. This episode introduces a portable, LLM-agnostic authoring path anchored to a single contract — the JSON Schema exported from the same Pydantic models that already enforce extra=forbid (ADR-0002) — so prompts, slash commands, and IDE validators all reference one source of truth and cannot silently drift from the renderer. The PII discipline is non-negotiable because real specs carry home addresses and hotel confirmation numbers; the pipeline therefore routes personal output to a gitignored private directory by default and repeats the rule at every layer (universal prompt guardrails, slash command save step, agent guide PII rules).

## What changed

- The CLI gained a schema-export verb that emits the Pydantic-derived JSON Schema in snake_case (matching YAML, not the runtime camelCase boundary crossed in the renderer) and supports a drift-check mode that exits non-zero when the committed schema is stale, so future model edits cannot ship without regenerating the contract. A new test pins that drift gate against the committed schema and asserts the top-level additionalProperties=false invariant that makes typos fail loudly. A portable conversion prompt is now the single LLM-facing definition of authoring rules — snake_case fields, SoC and time string formats, anti-fabrication rules for place_id, confirmation numbers, and street addresses — and a Claude Code slash command wraps it for in-repo use, defaulting output under the gitignored private trip directory and running the validator before declaring success. The agent guide formalizes the file-routing and PII contract for any LLM operating in the repo, and the Python sibling of the runtime AC-indicator algorithm (with paired tests) was added so the contract from ADR-0003 — Python and JS implementations must move together — has a real Python side to test against. The render command's default output path was moved to align with the gitignored renders directory, removing a silent disagreement between the CLI and the ignore rules.

## Evidence

- The CLI schema subcommand calls Trip.model_json_schema(by_alias=False) and maps --check failures to exit code 3, consistent with ADR-0004's typed-exception/exit-code funnel. tests/test_schema.py asserts the committed schema equals what the Pydantic models would emit today and that top-level additionalProperties is False. The universal prompt's §2 enumerates the hard validation rules tied to extra=forbid (ADR-0002). The slash command's Step 4 names the gitignored private directory as default output and Step 5 wires in the validate subcommand. The agent guide's 'PII rules — non-negotiable' section forbids committing real addresses, confirmation numbers, and phone numbers and reserves the public root for the sanitized sample. The gitignore tracks the private trips path with a .gitkeep so the directory survives a clean clone. The day summary at .agents/memory/daily/2026-05-14/summary.md and ADRs 0001–0008 cover the engine bootstrap but contain no reference to schema export, the slash command, or the private output zone — this episode is genuinely new durable ground.
